# API para listagem de contatos
Objetivo
<p> A proposta desse projeto é criar uma API que lista os dados de contato dos médicos de uma clínica de pediatria. Faremos isso acessando os dados armazenados no banco de dados da clínica.</p>


Manipular banco de dados;
Criar uma API com Node.js e Express;
Acessar banco de dados a partir de uma API.
